# 📈 Análisis Financiero Automatizado con IA (AAPL, MSFT, NVDA)

Proyecto en Python que automatiza la descarga de datos bursátiles del último año, genera gráficos interactivos avanzados y utiliza la inteligencia artificial de **Google Gemini** para redactar un análisis financiero detallado de las principales empresas tecnológicas.

---

## 🚀 Características Principales

- **Extracción de Datos Bursátiles:** Obtención automática de precios de cierre históricos utilizando `yfinance`.
- **Visualización Interactiva:** Gráficos dinámicos con `Plotly` (tendencias de cotización, simulación de inversión de $1,000 USD y precios promedio).
- **Análisis con Inteligencia Artificial:** Integración con la API de Google Gemini (`google-genai`) para interpretar tendencias de mercado y generar resúmenes automatizados.
- **Exportación de Reportes:** Generación automática de reportes interactivos en formato HTML.

---

## 🛠️ Tecnologías Utilizadas

* **Python 3.x**
* **yfinance** (Datos financieros)
* **Plotly** (Visualización interactiva)
* **Google GenAI SDK** (Análisis con IA)
* **Pandas** (Manipulación de datos)
* **Python-Dotenv** (Gestión de variables de entorno)
